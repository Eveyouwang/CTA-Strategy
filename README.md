# MTO 价差策略复盘

复现天勤量化（tqsdk）的公开示例策略 `tqsdk/demo/example/mto_spread.py` 并检验它是否可用。该策略用甲醇（MA，郑商所）、聚乙烯（L，大商所）、聚丙烯（PP，大商所）构造甲醇制烯烃的加工利润价差，按 z 分数做均值回归。

结论：这套规则在这三个品种上没有可验证的收益能力。本文所有数字由 `python run_all.py` 从原始日线重算，正文见 [report/report.md](report/report.md)。

## 结论

滚动检验，检验年 2019–2026 共 8 年，每年只用它之前 3 年的数据选参数。保守成交口径（次日开盘）、每腿每边 1 跳滑点、本金为 3 倍保证金：

| 风控 | 年化收益 | 最大回撤 | 夏普 | 夏普标准误 | 交易 |
|---|---|---|---|---|---|
| 固定手数 | −0.8% | 38.5% | −0.06 | ±0.37 | 48 |
| 按波动定手数 | +2.7% | 27.1% | 0.18 | ±0.37 | 53 |
| 再加金额止损 | −4.3% | 45.6% | −0.32 | ±0.38 | 59 |

三档的夏普都在一个标准误之内包含 0。按这个样本量，夏普要稳定在 0.2 左右并与 0 分开，需要约 80 年的同类数据。

把滑点从 0 跳测到 2 跳，每一档都按该档成本重新选参数，合计夏普在 −0.32 到 0.26 之间，全部落在标准误以内，零成本那一档三档风控都是负的。结论不由成本高低决定。

另外两个结果：

- 原脚本自带的回测区间（2023-11-01 至 2024-04-30，半年）夏普 1.66；同一套逻辑放到 2019-12 之后的 5.3 年，夏普 0.22。
- 按波动定手数同时改善了夏普和回撤；固定金额止损把两头都变差，它砍掉的是后来会回归的仓位。

## 三轮检验

| 轮次 | 做法 | 结果 |
|---|---|---|
| 第一轮 | 样本内 2015-05 至 2025-06 选参数并冻结，样本外 2025-07 起只跑一次 | 样本外保守口径年化 −2.8%、夏普 −0.07、7 笔交易 |
| 第二轮 | 样本内起点改到三腿交易时段一致之后的 2019-12-12，换月只在 01、05、09 月份中选 | 选出的参数与第一轮相同，样本外交易逐笔相同 |
| 第三轮 | 改用滚动检验，本金改为 3 倍保证金，逐档加风控 | 见上表 |

每一轮的设计都在运行之前写进 [PROGRESS.md](PROGRESS.md)；参数文件先提交、再跑样本外，提交顺序在 `git log` 里可查。待决定和未解决的问题写在 [BLOCKED.md](BLOCKED.md)。

## 方法要点

- **换月**。三腿用同一交割月，只在 01、05、09 中选，按前一交易日甲醇持仓量挑主力，在交割月前一个月的首个交易日之前换完，换月当天平旧开新、两边都计成本。原脚本把合约写死为 2409，到期前一个多月流动性已经转移，个人客户的持仓也不能进入交割月。
- **μ 和 σ 只用在持这组合约自己的历史**。换月当天的 z 用新合约组过去 w 天的价差算，不用"旧合约历史接新合约当日"的拼接序列，否则换月跳空会造出假信号。测试里有专门一条，并做过反向验证：故意改成窗口含当日就变红，改回来就变绿。
- **成交与成本**。信号每天收盘算一次，成交价报两套：信号日收盘为乐观口径，次日开盘为保守口径。每腿每边手续费取名义额的万分之一，另加滑点，1 单位单边成本中位数约 56 元，另测 0 跳和 2 跳。聚乙烯的最小变动价位在 2021-11-01 由 5 元改为 1 元，滑点按当时的跳价计；这个日期由大商所公告确认，与从成交价反推的日期一致。
- **数据体检**。每手吨数取合约表的 `per_unit`（甲醇 10 吨、聚乙烯和聚丙烯各 5 吨）；无成交日的收盘价用当日结算价补；两个交易所的交易日核对完全一致；郑商所合约代码为 4 位年月。
- **防过拟合**。参数只用样本内按固定规则选（网格的邻域平均，不取单点最高），选完写入 `params.json` 单独提交，之后才运行样本外。第三轮改用滚动检验，每个检验年对它自己那组参数都是没看过的数据。

## 复现

```bash
pip install -r requirements.txt
python run_all.py    # 重算三轮全部结果、图和报告，并核对第一轮结果与首次入库版本逐字节一致
pytest -q            # 17 项测试
```

仓库不含原始行情数据。`src/fetch_data.py` 用 tushare 接口一次性下载三个品种的逐合约日线（471 个合约、109,487 行）与合约表，需要自备 token：

```bash
TUSHARE_TOKEN=<token> TUSHARE_URL=<接口地址> python -m src.fetch_data
```

`run_all.py` 每次运行先核对 `data/` 两个文件的 sha256 与当初记录一致。tushare 的历史数据如有修订，重新下载得到的 sha256 会不同。

## 局限

- 只有日线。信号每天判断一次，盘中触发、三腿分腿成交、冲击成本都没有模拟；滑点按固定跳数假设，没有盘口数据校准。
- 手续费按名义额万分之一估计，与各期货公司的实际费率不同；报告给出 0、1、2 跳滑点的对照。
- 滚动检验每个检验年末强平，跨年不留仓；金额止损只测了保证金 25% 一个档位。
- 手数按连续数值计算，实盘 1 单位是 1 手聚乙烯加 1 手聚丙烯加 3 手甲醇，只能取整数倍。
- 第二轮的修改发生在看过第一轮样本外结果之后，它的样本外不构成独立检验；报告第 1 节写明了这一点。
